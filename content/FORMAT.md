# Outline format for concept files

- Plain text, UTF-8. One concept per line.
- Indentation = 2 spaces per level. Top-level lines (no indent) are the branch names under the root "Artificial Intelligence".
- Lines contain ONLY the concept / topic / algorithm / term name. No explanations, no bullets, no numbering, no colons, no trailing punctuation.
- Order children from basic to advanced (learning flow).
- No duplicate names among siblings. Same concept may appear in different branches if it truly belongs to both.
- Depth 3 to 7 levels. Leaves must be concrete, learnable items (an algorithm, a term, a parameter, a metric, a model name, a technique).
- Blank lines are ignored. Lines starting with # are comments.
